What's new

A click-through prototype for a smarter shortcut for routine commuters — built on top of the existing Home → Search → Ride Selection flow, using the same visual language.

NEW · HOME

"Your usual ride" chip

Appears below "Where to?" when the app predicts a routine trip (e.g. weekday evenings, CMU Campus → Home). Tapping it skips destination search entirely.

NEW · RIDE SELECTION

Pre-filled with a safety net

Pickup, destination, and last-used ride type are pre-filled with a live price and ETA. A banner clearly shows the predicted route, and the person must still tap "Confirm Standard" — nothing is requested automatically.

NEW · ERROR HANDLING

Edit, dismiss, or bail out

Edit jumps into search with the destination pre-filled so it's fast to correct. ✕ Dismiss closes the suggestion for now and returns home. "Not my usual trip" drops straight into a normal, empty search — no prediction gets in the way.

UNCHANGED

Original search & ride flow

Tapping the search bar still opens the standard Destination screen and full Ride Selection list, untouched, for anyone not taking a routine trip.
